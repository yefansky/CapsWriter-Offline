# 模型下载的若干问题

CapsWriter-Offline 完全离线运行，所有模型都在本地：

| 引擎名 | 准确性 | 速度 | 格式 | 调用方式 | 显卡加速 |
|------|-------|------|------|---------|---------|
| Paraformer | ★★★☆☆ | ★★★★★ | ONNX | sherpa_onnx | ❌ |
| SenseVoice-Small | ★★★☆☆ | ★★★★★ | ONNX | 自定义引擎 | ✅ |
| Fun-ASR-Nano | ★★★★☆ | ★★★★☆ | ONNX + GGUF | 自定义引擎 | ✅ |
| Qwen3-ASR-1.7B | ★★★★★ | ★★★☆☆ | ONNX + GGUF | 自定义引擎 | ✅ |

模型选择：

- 独显电脑优先用 Qwen3-ASR-1.7B-q5_k，准确率夯爆
- 集显电脑可尝试 Qwen3-ASR-1.7B-q4_k，如果延迟太高，可降至 Fun-ASR-Nano
- 性能太差则建议 SenseVoice-Small

性能参考（20s 音频转录延迟）：

| 模型 | CPU U9-285H | GPU RTX5050 |
|------|------------|------------|
| Paraformer | 0.6s | - |
| SenseVoice-Small | 0.6s | 0.15s |
| Fun-ASR-Nano | 2.0s | 0.5s |
| Qwen3-ASR-1.7B | 4.0s | 1.0s |

> Paraformer 通过 sherpa_onnx 调用，不支持显卡加速，且需要外挂标点符号模型 Punct-CT-Transformer，不建议使用，仅作纪念性保留。
> Qwen3-ASR 不具备时间戳能力，需要外挂时间戳模型 ForcedAligner 才能在文件转录时生成时间准确的 srt 字幕。

## 一、首次启动自动下载

从源码或发行包首次启动时，服务端会检查 `config_server.py` 当前选择的识别模型。必需文件缺失时，会自动完成：

1. 从官方 GitHub Models Release 下载对应压缩包；
2. 使用 `.part` 文件断点续传，网络中断后再次启动可继续下载；
3. 检查发布资产的固定文件大小和 SHA-256 摘要，拒绝损坏或被替换的压缩包；
4. 防止压缩包路径越界后安全解压到正确的 `models/` 子目录；
5. 再次检查必需文件，确认完整后才继续加载识别引擎。

默认只下载当前用到的模型：

| 当前引擎 | 首次自动下载 |
| --- | --- |
| `qwen_asr` | `Qwen3-ASR-1.7B-q4_k.zip` |
| `fun_asr_nano` | `Fun-ASR-Nano-GGUF.zip` |
| `sensevoice` | `Sensevoice-Small-ONNX.zip` |
| `paraformer` | `Paraformer.zip` 和必需的 `Punct-CT-Transformer.zip` |

Qwen3 ForcedAligner 不会在普通麦克风听写时额外下载；首次进行需要精确时间戳的文件转录时才按需下载。

下载进度、校验和失败原因都写入 `logs/server_latest.log`，也会实时显示在管理器的“运行日志”页。大模型首次下载可能需要较长时间，管理器会持续等待服务端就绪。

相关配置：

```python
class ServerConfig:
    auto_download_models = True
    qwen_asr_download_variant = 'q4_k'  # 也可改为 'q5_k'
    model_download_timeout = 60
```

- `q4_k` 体积较小，是新部署默认值；`q5_k` 体积更大、精度略高。
- 设置环境变量 `CAPSWRITER_MODEL_BASE_URL` 可以替换下载镜像的基础地址，资产文件名必须与官方 Release 一致。
- 若不希望程序联网，把 `auto_download_models` 改为 `False`，然后按下文手工下载。

下载临时文件位于 `models/.downloads/`，成功安装后自动清理；失败时 `.part` 会保留以便续传。

## 四、如何切换引擎

在 [`config_server.py](../config_server.py) 中设置：

```python
model_type = 'fun_asr_nano'    # 可选：'qwen_asr', 'fun_asr_nano', 'sensevoice', 'paraformer'
```
